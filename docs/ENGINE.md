# Kompas Engine v0.3 — контракт исполнения

## Назначение

Специализированный локальный исполнитель **двух демонстрационных кадровых процедур**. Это не конструктор произвольных Mermaid-графов, не серверный Script Runner и не официальная реализация норм KPRM. Исходный код Script-mod-flow не используется.

## Зависимости в порядке подключения

```text
data/competencies.js        каталог тестовых компетенций, уровни 1–4
data/procedures.js          описание шагов для periodic и first
js/assessment.js           чистые вычисления / сводки
js/validation.js           именованные проверки обязательных условий
js/workflow.js             интерпретатор переходов между шагами
js/session.js              действия над состоянием + технический журнал
js/engine.js               совместимый API старого app.js
js/state.js                первоначальное состояние, миграция, sessionStorage
js/assistant.js            офлайн-справочник + локальная Ollama
js/app.js                  UI и экспорт
```

Нет Node/npm-сборки, `fetch()` локальных файлов или обязательного API. Скрипты являются обычными файлами с `window.KOMPAS_*`.

## API движка

- `KOMPAS_WORKFLOW.getProcedure(track)` — описание соответствующей процедуры либо `null`;
- `.getSteps(track)` — упорядоченный список объектов `{id,title,subtitle,requires}`;
- `.canNavigate(state, stepIndex)` — проверка **всех** ворот до целевого этапа, включая прямые переходы вперёд;
- `.canComplete(state)` — проверка всех обязательных условий независимо от текущего экрана;
- `KOMPAS_VALIDATION.check(state, ruleIds)` — отказ при отсутствии нужных данных, включая неизвестные правила;
- `KOMPAS_ASSESSMENT.summaryFor(state, competencyId)` — индикаторы, средняя, предлагаемая оценка, решение, обоснование и состояние валидности;
- `.totals(state)` — общий статус прохождения индикаторов и решений;
- `KOMPAS_SESSION.changeTrack/toggleCriterion/rate/decide/navigate/finalize` — проверенные изменения сессии;
- `.record` — технические события без персональных текстов.

`KOMPAS_ENGINE` сохраняет прежний API для UI и делегирует операции разделённым модулям.

## Процедуры

| Этап | Periodic | First |
|---|---|---|
| 1 | Rozpoczęcie | Rozpoczęcie |
| 2 | Kryteria | Kryteria |
| 3 | Obserwacje | Obserwacje |
| 4 | Rekomendacja | Rekomendacja |
| 5 | Rozmowa | Plan rozwoju |
| 6 | Dokument | Dokument |

В обоих случаях этап 6 требует валидных оценок и решений руководителя. В **first** дополнительно введено *демонстрационное* требование заполнить план действий (минимум 8 символов). Это пример того, как процедуры могут отличаться, а **не утверждение о юридической обязанности**. Другие реальные правовые различия будут доступны только после получения и проверки соответствующих материалов KPRM. Разные наборы компетенций по умолчанию уже находились в v0.2.

## Оценивание

Без изменений от v0.2: три индикатора на компетенцию, равные веса, среднее арифметическое, `Math.round`, итоговый уровень 1–4. Для каждой сводки доступна строка `explanation`. **Это демонстрационная шкала, не профессиональная или нормативная методика.**

Итоговую оценку указывает только руководитель. Если она отличается от рекомендации, проверяется обязательное обоснование длиной минимум восемь символов. При изменении индикатора предыдущее решение по компетенции удаляется; при удалении компетенции очищаются её наблюдения и решение.

## Сохранение / совместимость

Используется **прежний ключ** `kompas-competencji-mvp-v1` в `sessionStorage`: нет принудительного сброса данных при обновлении. Объект состояния имеет `version: 2`, содержит массив `history` и мигрирует существующий `version: 1` при загрузке, сохраняя введённые поля, заметки, решения и сообщения помощника; ошибочно записанные v0.2 заметки из `observation` также переносит в `observations` без удаления исходного поля. События в `history` ограничены последними 120 и не содержат ФИО, заметок или текстовых обоснований.

Пользовательские данные по-прежнему живут только в текущей вкладке. Не использовать без доработок для реальных кадровых данных. Ни журнал, ни UI не являются криптографически защищёнными или неизменяемыми.
