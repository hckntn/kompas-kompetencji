# Traceability: требования -> MVP

Источник: `references/opis-wyzwania.pdf`.

| Требование | Статус | Что можно показать |
|---|---|---|
| §3 Две ścieżki: pierwsza / okresowa | Частично | Раздельный выбор и начальный набор критериев; юридические правила не реализованы |
| §3 Wskaźniki behawioralne | Демо | 5 синтетических компетенций × 3 наблюдаемых индикатора |
| §3 Sugerowany poziom | Реализовано в демо-модели | Чистая формула `Math.round(mean)`; вывод средней и уровня |
| §3 Ostateczna decyzja przełożonego | Реализовано | Независимый выбор оценки, обоснование отклонения |
| §3 Rozmowa i dokumentacja | Реализовано частично | Форма подготовки и неофициальный отчёт |
| §3 HR/administrator | Частично | Статусы и сроки, 2 фиктивные записи |
| §4 Działający prototyp | Реализовано | Полный путь из 6 этапов без сервера |
| §4 Opis AI i architektury | Документировано | `README.md`, `ARCHITECTURE.md` |
| §5 PDF | Реализовано для demo | Browser Print / Save as PDF, без официальных шаблонов |
| §5 Auth/RBAC | Не реализовано | Только архитектурный план |
| §5 Bezpieczeństwo danych | Частично | Без облака, `sessionStorage`, демо-данные |
| §5 Assistant oparty na źródłach | Частично | Справочный offline режим по brief/regulamin; опционально реальный локальный LLM |
| §5 Aktualne prawo i model KPRM | Не реализовано | Файлы не были предоставлены |
| §5 EZD/QNT | Не реализовано | Точки расширения в документе архитектуры |
| §6 Jedna kompletna ścieżka | Реализовано в демо-модели | Старт → критерии → поведение → предложение → решение → печать |

**Граница честности:** до получения официальных источников нельзя демонстрировать правильность оценки *по законодательству*. Можно демонстрировать UX и программную механику.
